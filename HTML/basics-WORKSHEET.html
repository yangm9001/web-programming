Question 1

What is the significance of the html element in an html document?

It is the root element, which means that it contains all of the other elements on the page.
Question 2

What is the purpose of the head element in an html document?

It contains information about the web page.
Question 3

What is the purpose of the title element in an html document?

It displays the title of the page in the browser tab, inside the head element.
Question 4

What is the purpose of the body element in an html document?

It contains the content of the page that is visible in the browser window.
Question 5

What is the difference between an inline element and a block element?

Block element will stretch out as much width as it can and inline element will only occupy as much width as the content requires.
Question 6

What is a self-closing tag?

An element that can't serve as a container, cannot hold any content or anything.
Question 7

Explain the syntax for adding an attribute to an HTML element?

Adding an attribute to a HTML element is like additional instructions telling the browser how the element should look or behave.
